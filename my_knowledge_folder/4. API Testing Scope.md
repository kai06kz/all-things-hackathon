Different API architectures require different testing approaches.

**REST API**
- Validate JSON response
- Verify HTTP status code
- Check response time
- Validate request and response body

**SOAP API**
- Validate XML structure
- Verify SOAP Envelope and Body
- Check SOAP Fault messages

**GraphQL**
- Validate GraphQL query syntax
- Verify requested fields are returned
- Ensure unnecessary data is not returned

Although REST, SOAP, and GraphQL are common API architectures, **the API Testing activities within our team primarily focus on REST APIs**. Therefore, the remaining sections of this document will concentrate on REST API concepts, request and response structures, HTTP methods, status codes, data formats, and the tools used for REST API Testing.
