The common types of APIs are REST, SOAP, and GraphQL. These are different styles or architectures used to build APIs. Think of them as different languages people use to communicate. Although all three can perform the same task (such as retrieving customer information), they follow different communication rules.

**A. What is REST API?**

REST (Representational State Transfer) is the most widely used API architecture today.

It uses standard HTTP methods such as GET, POST, PUT, DELETE, and PATCH.

- Lightweight
- Easy to understand
- Uses JSON
- Suitable for web and mobile applications

**Example**
Request - GET /customers/1001

Response:
{
  "customerId": 1001,
  "name": "John Tan",
  "email": "john@gmail.com"
}

**B. What is SOAP API?**

SOAP (Simple Object Access Protocol) is an older API protocol that uses XML to exchange information.

SOAP follows strict standards and includes additional security and reliability features, making it common in enterprise and banking systems.

- Uses XML
- More secure and structured
- More complex than REST
- Common in legacy enterprise applications

**Example** 
Request
<soap:Envelope>
   <soap:Body>
      <GetCustomer>

         <CustomerId>1001</CustomerId>

      </GetCustomer>
   </soap:Body>
</soap:Envelope>

Response
<Customer>
    <CustomerId>1001</CustomerId>
    <Name>John Tan</Name>
</Customer>

**C. What is GraphQL?**

GraphQL is a query language for APIs developed by Facebook.
Unlike REST, the client specifies exactly what information is required.
This avoids sending unnecessary data.

**Example**
Request:
query {
  customer(id:1001) {
    name
    email
  }
}

Response:
{
  "data": {
    "customer": {
      "name": "John Tan",
      "email": "john@gmail.com"
    }
  }
}

Notice that only **name** and **email** are returned.
