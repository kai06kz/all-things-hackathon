
REST (Representational State Transfer) 
- The most widely used type of web API
- Uses HTTP methods like **GET**, **POST**, **PUT**, and **DELETE**
- Works with URLs that represent resources
- Stateless (each request is handled independently)

What is stateless means? 
> **Every request is independent. The server does not remember anything about previous requests.**

Each request must contain all the information needed for the server to process it.

Example:
Imagine the waiter has **no memory** (stateless).

❌ Not stateless:
- You order a drink.
- Five minutes later you say, "Give me another one."
- The waiter remembers your previous order.

✅ Stateless:
- Every time you order, you must say:
    > "I'd like an iced coffee."

- The waiter does **not** remember what you ordered before.

Similarly, every API request must include everything the server needs (such as authentication, parameters, and request body).
