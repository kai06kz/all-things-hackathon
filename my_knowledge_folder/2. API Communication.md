A REST API follows the **request-response communication model**. 
1. **Client sends an HTTP Request to Server**
2. **Server processes the request**
3. **Server returns an HTTP Response**

### What is inside a Request?
- HTTP Method (GET, POST, PUT, DELETE, PATCH)
- URL (Endpoint)
- Headers
- Request Body (for POST/PUT/PATCH)

```
GET /customers/1001 HTTP/1.1
Host: api.bank.com
Authorization: Bearer <token>
Accept: application/json
```

---
### What is inside a Response?
- HTTP Status Code
- Response Headers
- Response Body

```
HTTP/1.1 200 OK
Content-Type: application/json
```

```
{
  "customerId": 1001,
  "name": "John Tan"
}
```
