**1. What is an API?**

**API** stands for **Application Programming Interface**. In simple terms, it’s a way for software programs to communicate and exchange information.

**Think of an API as a restaurant waiter:**

- You (client) place an order (API request) based on the menu (API Documentation).
- The kitchen (the server) prepares the order.
- The waiter (API) delivers your order (API response).

**Real Word Example**
Imagine you are using the **Maybank MAE mobile application** to check your account balance.

1. You open the MAE App
2. Click "Account Balance"
3. The App sends an API Request
4. Backend Server
5. Database retrieves your account balance
6. Backend returns an API Response
7. The App displays RM 3,520.75

Although it appears that the mobile application knows your account balance, it actually retrieves the information through an API.
